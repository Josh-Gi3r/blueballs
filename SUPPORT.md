# Support

Blueballs is community-supported open-source software.

## Questions and bugs

Use GitHub issues for reproducible bugs and scoped feature proposals. Include the Blueballs commit/version, deployment mode, environment and a minimal reproduction.

## Security

Do not open public issues for suspected vulnerabilities, exposed credentials, bypasses or financial-state integrity problems. Follow `SECURITY.md` and use GitHub private vulnerability reporting.

## Production deployments

The repository contains reference implementations and deterministic adapters alongside components intended to be reusable in production architectures. Blueballs does not provide regulated credentials, licences, insured accounts, custody, liquidity or operational guarantees. Deployment operators remain responsible for selecting, validating and operating their providers and controls.

## Compatibility

Supported behaviour is defined by the versioned API/specification and documented contracts. Internal implementation details should not be treated as stable integration surfaces.
