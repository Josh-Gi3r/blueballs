## [0.1.0] - 2026-08-28

Initial public release of the Blueballs reference platform.

### Included

- product interfaces for accounts, cards, transfers and onboarding;
- a tenant-isolated banking API with 181 documented operations;
- exact decimal accounting and a double-entry ledger;
- the Sandbox Builder and test-payment workflow;
- the canonical FX node, domain packages, SDK and simulator;
- optional Solidity settlement contracts;
- Node.js, Docker and Cloudflare reference runtimes;
- OpenAPI contracts, examples and local verification commands.
