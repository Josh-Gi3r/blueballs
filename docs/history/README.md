# Historical project records

These files preserve the early Blueballs scope and milestone plans for project
history. They are **not current product contracts or release instructions**.

The early documents predate the canonical FX engine, the 174-operation banking
catalogue, the tenant-security model, and the current provider-transparency
policy. In particular, their 144/175 operation counts and prohibition on naming
providers have been superseded.

Use the current sources instead:

- [`README.md`](../../README.md) — product overview and local quickstart;
- [`VISION.md`](../../VISION.md) — product direction and boundaries;
- [`ARCHITECTURE.md`](../../ARCHITECTURE.md) — current system design;
- [`KNOWN-LIMITATIONS.md`](../../KNOWN-LIMITATIONS.md) — current limitations;
- [`RELEASE.md`](../../RELEASE.md) — publication procedure;
- [`src/endpoints.ts`](../../src/endpoints.ts) and
  [`public/openapi.yaml`](../../public/openapi.yaml) — banking catalogue and
  machine-readable contract.

Do not copy release claims, counts, provider rules, or commands from this folder
without revalidating them against the current tree.
